# نجم الصف V2 — Mobile First

هذه النسخة مبنية لتعمل كواجهة ثابتة على GitHub Pages مع قاعدة بيانات Supabase.

## قبل النشر
1. أنشئ مشروعًا في Supabase.
2. افتح SQL Editor والصق محتوى `supabase_schema.sql` ثم نفّذه.
3. أنشئ حسابات المعلم/أولياء الأمور من Authentication > Users.
4. أضف سجل `profiles` لكل مستخدم بالـ id نفسه، وحدد role.
5. أنشئ الصفوف والطلاب وروابط `parent_students`.
6. انسخ `config.example.js` إلى `config.js` وضع Supabase URL وanon/publishable key.
7. ارفع الملفات إلى GitHub Repository.
8. فعّل GitHub Pages من Settings > Pages.

## مهم جدًا
- لا تضع `service_role` key داخل المشروع أو GitHub.
- المفتاح الموجود في الواجهة يجب أن يكون anon/publishable key فقط.
- لا تضع بيانات الطلاب الحقيقية في ملفات المشروع.
- فعّل RLS كما هو موجود في SQL قبل استخدام بيانات حقيقية.

## ملاحظة V2
النسخة الحالية تركز على بنية الحسابات، قاعدة البيانات، التقييم الحقيقي، وصلاحيات الوصول. شاشة الإدارة المتقدمة، إضافة الطلاب من الواجهة، ربط ولي الأمر تلقائيًا، التقارير الشهرية، الشارات، والـ PWA offline يمكن توسعتها في V2.1 بعد اختبار هذه النسخة.
