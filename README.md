# نجم الصف V2 — النسخة المتكاملة

نظام متابعة طلاب Mobile First يعمل مع GitHub Pages + Supabase.

## الوظائف
- دخول المعلم وولي الأمر عبر Supabase Auth.
- إدارة الطلاب: إضافة، تعديل، حذف، بحث.
- الصف والشعبة وبيانات ولي الأمر.
- ربط الطالب بحساب ولي الأمر عبر البريد الإلكتروني.
- تقييم 1–10 في ستة محاور: التحصيل، المشاركة، الانضباط، الواجبات، التطور، السلوك.
- الحضور: حاضر، غائب، متأخر، بعذر.
- ملاحظات الطلاب.
- الإنجازات والجوائز.
- تقارير ومتوسطات.
- لوحة خاصة لولي الأمر.
- RLS لحماية البيانات.
- PWA.

## الإعداد مرة واحدة
1. افتح Supabase > SQL Editor وشغّل `supabase_schema.sql` كاملًا.
2. أنشئ حساب المعلم من Authentication > Users.
3. بعد إنشاء المستخدم، خذ UUID الخاص به ونفّذ:
   `update public.profiles set role='teacher' where id='UUID';`
4. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub.
5. فعّل GitHub Pages من branch `main` والمجلد `/root`.
6. افتح الموقع وسجّل دخول المعلم.
7. من إدارة الطلاب أضف الطلاب. عند إدخال بريد ولي الأمر، سيتمكن حساب ولي الأمر بهذا البريد من رؤية الطالب.

## الأمان
`config.js` يحتوي Publishable key فقط. لا تضع `sb_secret_` أو `service_role` في GitHub.
