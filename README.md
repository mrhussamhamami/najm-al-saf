# نجم الصف V2

## النشر على GitHub Pages
1. فك ضغط الحزمة.
2. ارفع الملفات الموجودة مباشرة إلى جذر مستودع `najm-al-saf`، بحيث يكون `index.html` في الجذر وليس داخل مجلد فرعي.
3. من إعدادات GitHub Pages اختر الفرع المستخدم ومجلد `/(root)`.
4. انتظر اكتمال النشر ثم افتح الموقع.

## تنبيه قاعدة البيانات
هذه الحزمة تستخدم إعدادات Supabase الحالية من `config.js`. لا تشغّل ملف `supabase_schema.sql` قديمًا ولا تغيّر مخطط قاعدة البيانات الحالية من أجل هذه الخطوة.

## ملاحظات
تم تضمين واجهة التطبيق الحالية وملفات إعداد النشر. فحص الصياغة البرمجية لا يغني عن اختبار تسجيل الدخول والعمليات والصلاحيات على قاعدة Supabase الحية. إنشاء حسابات المعلمين يعتمد على نشر Edge Function `create-teacher` في Supabase بشكل منفصل إن لم تكن منشورة مسبقًا.
